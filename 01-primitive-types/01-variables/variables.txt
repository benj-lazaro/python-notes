Variables
---------
- One of the core concepts in programming
    - Used for storing data in the computer's memory
        - Python interpreter allocates memory to store data

    - References to the location where data is stored in memory
        - Functions as a "label" to that specific memory location

    - Can be where anywhere in the program
        - To access data stored in memory
        - To overwrite previous stored data with a new one


- Supported data types
    - Built-in Primitive data type
        - Boolean
            - True | False

        - Number
            - Float
            - Integer

        - String
            - Text enclosed within a pair of ""
